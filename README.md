# 🎤 Projeto Web: Hannah Montana (Nostalgia & Prática HTML)

Uma página web simples sobre a série e as músicas de **Hannah Montana**, criada como projeto prático durante o meu **Ensino Médio Técnico em Informática**. 

---

## 📌 Sobre o Projeto

Na época do curso técnico, eu era completamente viciada nas músicas da Miley Cyrus e no universo de Hannah Montana. Como estávamos aprendendo a estrutura básica de desenvolvimento web, uni o útil ao agradável para praticar os primeiros conceitos de marcação de texto e estruturação de páginas.

Este projeto foi mantido no seu estado original (ou com pequenos ajustes) como uma forma de registrar a minha evolução e os meus primeiros passos na área da tecnologia! 🚀

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Para a estruturação completa dos elementos e conteúdos da página.

---

## 🎯 Objetivo do Repositório

* Registrar meu histórico de aprendizado no ensino técnico.
* Praticar o uso do **Git e GitHub** para versionamento de código.
* Guardar com carinho um projeto nostálgico dos meus tempos de fã! ✨
